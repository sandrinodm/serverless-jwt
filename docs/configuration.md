# Configuration

[README](../README.md) · [Getting started](getting-started.md) · [Configuration](configuration.md) · [Errors](errors.md)

Generated by `pnpm docs:reference` from `options.ts` metadata and resolved defaults. Edit the implementation metadata, then regenerate. CI rejects stale output and option interfaces without metadata.

Create one verifier per trust policy and reuse it. Options are copied and frozen at construction. Durations are seconds unless stated otherwise.

| Option                      | Default               | Validation and purpose                                                                                                                                                                                                   |
| --------------------------- | --------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `issuer`                    | `required`            | Required nonempty exact string. Without jwksUri, an HTTPS URL; HTTP only for explicitly permitted loopback hosts. No credentials or fragment in network endpoints. A direct jwksUri permits a non-URL issuer identifier. |
| `audience`                  | `required`            | Required nonempty string or nonempty array of nonempty strings. Configure the API resource, distinct from ID-token audiences.                                                                                            |
| `algorithms`                | `["RS256"]`           | Nonempty array containing only Algorithm values. HS algorithms and none are forbidden.                                                                                                                                   |
| `jwksUri`                   | `unset`               | Optional HTTPS endpoint (or explicitly permitted HTTP loopback); no credentials or fragment. Bypasses discovery.                                                                                                         |
| `discovery`                 | `"oidc"`              | oidc, oauth, or false. false requires jwksUri.                                                                                                                                                                           |
| `profile`                   | `"generic"`           | generic or rfc9068. RFC 9068 requires an access-token typ and exp, iat, sub, client_id and jti; requireExp cannot be false.                                                                                              |
| `requireExp`                | `true`                | Boolean; false is allowed only with generic. Issuer and audience always remain required.                                                                                                                                 |
| `verifyTimeout`             | `10`                  | Integer seconds, 1–60; total verification deadline including mapping. Range: 1–60.                                                                                                                                       |
| `requiredClaims`            | `["iss","aud","exp"]` | Array of nonempty claim names; adds to issuer, audience and profile requirements.                                                                                                                                        |
| `clockTolerance`            | `5`                   | Integer seconds, 0–300. Range: 0–300.                                                                                                                                                                                    |
| `maxTokenAge`               | `unset`               | Optional integer seconds, 1–31536000; requires iat. Range: 1–31536000.                                                                                                                                                   |
| `maxTokenLength`            | `8192`                | Integer compact-token character limit, 512–65536. Range: 512–65536.                                                                                                                                                      |
| `minRsaModulusLength`       | `2048`                | Integer bits, 2048–Number.MAX_SAFE_INTEGER; does not permit weak RSA keys. Range: 2048–9007199254740991.                                                                                                                 |
| `keys`                      | `see below`           | Object containing the key/network policy below.                                                                                                                                                                          |
| `shareInflight`             | `runtime detection`   | Boolean. Default is detected from runtime I/O ownership. Unsafe sharing is disabled on workerd and Vercel Edge.                                                                                                          |
| `allowInsecureLocalhost`    | `false`               | Boolean; permits HTTP only for localhost, 127.0.0.1 and [::1]. Does not weaken TLS for remote hosts.                                                                                                                     |
| `realm`                     | `"api"`               | ASCII printable string; quotes and backslashes are escaped in the challenge. Controls are rejected.                                                                                                                      |
| `fetch`                     | `globalThis.fetch`    | Trusted function implementing fetch; receives a cancellation signal. Custom fetch must respect the trust policy.                                                                                                         |
| `mapClaims`                 | `verified claims`     | Optional function from verified claims to an object or promise-like object. Runs within the total deadline; failures become mapping_failed.                                                                              |
| `onDiagnostic`              | `unset`               | Optional function receiving redacted Diagnostic events. Throws and rejected thenables are isolated.                                                                                                                      |
| `clock`                     | `Date.now`            | Optional object with now() returning epoch milliseconds. Invalid results fail verification.                                                                                                                              |
| `keys.cacheMaxAge`          | `600`                 | Integer seconds, 0–86400; fresh JWKS lifetime. Range: 0–86400.                                                                                                                                                           |
| `keys.cooldown`             | `30`                  | Integer seconds, 0–86400; global per-verifier unknown-key refresh cooldown. Range: 0–86400.                                                                                                                              |
| `keys.timeout`              | `5`                   | Integer seconds, 1–60; response headers and body deadline. Range: 1–60.                                                                                                                                                  |
| `keys.maxResponseBytes`     | `524288`              | Integer decoded bytes, 1–16777216. Range: 1–16777216.                                                                                                                                                                    |
| `keys.maxKeys`              | `100`                 | Integer key entries, 1–10000. Range: 1–10000.                                                                                                                                                                            |
| `keys.staleIfError`         | `0`                   | Integer seconds, 0–86400; outage-only stale-key allowance. Zero disables stale use. Range: 0–86400.                                                                                                                      |
| `keys.maxConcurrentFetches` | `4`                   | Integer requests, 1–100; limit when in-flight sharing is disabled. Range: 1–100.                                                                                                                                         |

Use [provider-specific audience and profile settings](providers/README.md). See [keys and outages](keys-and-outages.md) before enabling stale keys.
